Writes one test message at each log level, from Debug to Emergency, to the "monolog-test" channel. Messages at or above the Log File Minimum Log Level are written to the log file. If email is enabled, those at or above the Email Minimum Log Level are sent together as one email, and if Slack is enabled, those at or above the Slack Minimum Log Level are posted as one Slack message — but a message already sent within the deduplication timeout is not sent again, so running the test twice in quick succession sends nothing the second time. Handlers added in config.php receive the messages too. Nothing else on the forum is changed.
